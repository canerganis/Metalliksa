### Review fix round (2026-10-04)

- **Security (auth bypass, fixed).** `tokenAuth` decided on the raw `req.originalUrl`, but Express routes on the parsed pathname. An absolute-form request target (`GET http://host/api/lpbf/capabilities HTTP/1.1`) therefore skipped login and still reached the API handler: unauthenticated access to every `/api` route in login mode, including the Docker default.
  - Reproduced on the built `dist/server.cjs` (token mode, loopback): 200 with the capabilities JSON and no credentials.
  - Fix: absolute-, authority- and asterisk-form targets now get 400 (`rejectNonOriginForm`). Auth and rate limiting protect a path when its raw lower-cased form or its canonical form (percent-decoded, slashes collapsed, dot segments removed) starts with `/api`. The `/api/health` exemption matches the raw form only.
  - `tests/server-request-target.test.ts` sends raw request lines over HTTP in access-code and token modes. Every variant is 400 or 401 with no protected body: absolute-form, case, `//`, `%2e`, `./`, `../`, `;params`, `%61`, `%2f`, backslash, aliases of `/api/health`, and `*`.
  - After the fix the same probe on the bundle and on the container gives 400 for absolute-form, 401 for the path variants, and 200 for `/api/health`.
- **Fail-fast start.** `server/startupGuard.ts`, the first import of `server.ts`, exits 1 with a clear message when `<cwd>/python/persistent_ipc_service.py` is missing, or, in production, `<cwd>/dist/index.html`. It runs before the Python worker starts (tested on the bundle).
- **Build context.** `.dockerignore` now also excludes the following untracked local trees:
  - nested `.env` files, virtualenvs, root `tmp*`, `python/.tmp-*`
  - warp and pytest caches, `python/python`, `python/scratch-manufactured`, `python/codex-lpbf-test-tmp`, `python/lpbf-run-shape-*`
  - the compiled OpenFOAM tree, `data/benchmark/**/raw`, and the `spparks` gitlink

  Measured by copying the context into a throwaway image: the main developer checkout went from 1115 MB / 2855 files to 310 MB / 1420 files. A clean worktree is 308 MB / 1334 files. The rest of the difference is the source tree, not payloads.
- **Image ownership.** Only `/data`, the WORKDIR-relative default data directories belong to uid 10001. The code trees (`dist`, `node_modules`, `python`, `data`, `assets`, `docs/sources/in625`) are root-owned and read-only for that user.
  - Checked with `--cap-drop ALL --security-opt no-new-privileges` and a named volume. After login, capabilities, Python status, an estimate and a small standard LPBF job ran; the job completed.
  - `docker diff` showed no write outside `/tmp`, and the logs had no permission errors. The health status was `healthy`.
- **Compose.** Publishes `127.0.0.1:3000:3000` by default, drops all capabilities, sets `no-new-privileges`, and inherits the image `HEALTHCHECK`, which uses `$PORT`. `docker compose config -q` passes; `docker compose up` was not run.
