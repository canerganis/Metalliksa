## Kaynakla düzeltilmiş ortak karar

1. **Üretim scope'u genişletme:** Yeni fizik, materyal değeri, otomatik kalibrasyon, focus kontrolü veya GPU-speed/production iddiası ekleme. ec3 ölçüm/source-label fix'ini aynı adayın kanıtıyla kapat.
2. **Clean gate'i bitir ve sürümünü bağla:** Root'un son terminal sonucu: native fresh context locked npm 850 paket / lint PASS; full unit **372 total: 370 PASS / 1 FAIL / 1 SKIP**, 55.157 s. Tek fail `tests/vite-watch.test.ts:9`, 'source watcher must become ready', 8.252 s; **build çalıştırılmadı**. Bu ilerleme model yanıtlarındaki prompt-time 'Node gate açık' durumunu günceller ama full clean PASS oluşturmaz. Watcher köken incelemesi başka ajana ait; bu audit yeni köken/fix iddiası kurmaz. Locked policy, seçili Python, final source hash ve skip'ler ayrı kaydedilir.
3. **Browser erişimi geldikten sonra gerçek UI:** `live-acceptance-plan.md` esas alınır. Önceki userdenial sürerken retry/API/proxy/DOM-script UI taklidi yok. Dört normal completed run: baseline(method+hemenarchive), manual(absent), conditionlessJSON(absent), complete22(explicit worker-matched fakat user-supplied-unverified). Local malformed/unknown/numeric/partial denemeleri yeni job oluşturmadan hata göstermeli.
4. **Ucuz state gates:** Complete result'ta input60→61 stale,60'a dönüş; gerçek reload'da executed snapshot korunması. Draft/current controls kalıcıymış varsayılmaz. Fresh same-input repeat ile distinct runningjob → keyboardCancel → cancelled/no result/no completed archive → reload. Completion yarışını cancelPASS sayma. Baseline'ın aynı aday portable export/import/isolated restore/reload turu ve gerçek dosya hashleri ayrı.
5. **Recovery ve kapanış:** Root mevcut kritik error/recovery kabulünü ec3 revizyonuna owner-only kapsamda bağlar; artifact/partial/no-result ayrımı kalır. OperatorPASS, moving-source inconclusive, NISTunavailable ve experimentalunvalidated ayrı durumlar olarak raporlanır. Kalan software/browser/recovery gate'leri tamamlanmadan fullV1 accepted denmez.
